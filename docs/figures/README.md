# Published example figures

The two `case_ev9v_*.png` figures are derived from the EV9V dataset by Bo Gou and collaborators:
https://huggingface.co/datasets/bgx666/EV9V . The dataset card identifies its license as
Creative Commons Attribution 4.0: https://creativecommons.org/licenses/by/4.0/ .

Modifications: this project's v7 preprocessing crops/masks the imaging region and assembles diagnostic
panels with annotations and reduced display resolution. The figures illustrate preprocessing;
they are not clinical validation. The dataset license applies to the underlying images separately
from this repository's MIT software license.

Mixed-dataset overviews, Unity-derived images, and other figures without verified redistribution
permission remain in the local ignored outputs directory and are not part of the published history.
